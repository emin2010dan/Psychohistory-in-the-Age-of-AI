## 🔍 Step 1: Pattern Mining — "What Repeats?"

The first step is not to detect historical cycles, but to code **repeating structural dynamics**. Repetitions are not "the same event recurring," but "the same mathematical signature expressed through different content."

### Basic Wave Formulation

We code each historical variable (debt, trust, technology adoption, migration) over time in the following structure:

```math
f_i(t) = A_i(t) · sin(ω_i·t + φ_i(t)) · e^(λ_i·t) · M_C(C(t)) + ξ_i(t)
```

| Parameter | Meaning | Psychohistorical Correspondence |
|-----------|---------|--------------------------------|
| `A_i(t)` | Amplitude envelope | Intensity of the event (e.g., debt/GDP, inequality) |
| `ω_i` | Eigenfrequency | Cycle period (e.g., hegemonic ~0.0125 year⁻¹) |
| `φ_i(t)` | Dynamic phase | Synchronization/misalignment with other waves |
| `λ_i` | Growth/decay coefficient | Positive: regime change; negative: return to equilibrium |
| `ξ_i(t)` | Stochastic noise | War, pandemic, technological leap |
| `M_C(C(t))` | Cultural modulation operator | Same shock resonating differently across cultures |

> **Why is ReLU forbidden?**  
> The ReLU (`max(0,x)`) activation function used in traditional neural networks zeroes out the negative phase. But in history, "stagnation," "retreat," and "erosion" are also phases. In psychohistory models, **spectral integrity** must be preserved; the wave form must be maintained.

## ⚙️ Step 2: Not Time, but "Causal Velocity"

An inflation wave that took three generations 2,000 years ago may release the same energy in 3–5 years today through the same mechanism. Measuring by calendar year ignores history's "friction coefficient" and "transmission speed."

### Normalized Causal Time

```math
T_normalized = T_calendar × (μ / v)
```

| Era / Mechanism | Transmission Speed (`v`) | Friction (`μ`) | Wave Character |
|----------------|--------------------------|----------------|----------------|
| Ancient Mint | Low (months/years) | High (logistics, physical metal) | Long period, slow decay |
| Industrial/Communication (19th c.) | Medium (telegraph, train) | Medium (slow capital movement) | Shortening period, sharp peaks |
| Digital QE + Social Media (21st c.) | Very High (seconds) | Low (algorithmic amplification) | High frequency, sudden phase jumps |

Without this normalization, the model produces "false resonance" warnings; we fall into the error of measuring Rome and 2025 with the same ruler.

## 🧠 Step 3: Emotional Regime Vector — "Humans Are Not Rational, They Are Emotional"

Humans mostly decide with emotions; they use logic afterward as a wrapper. Therefore, psychohistory codes the societal emotional state as a **3-dimensional latent regime vector**:

```math
Ψ(t) = [E(t), K(t), P(t)]  ;  E + K + P = 1
```

| Regime | Definition | Effect on Waves |
|--------|------------|-----------------|
| **E (Emergency/Hero)** | War, crisis, external threat | `ω↑` (decisions in hours/days), `μ↓` (flexible institutions), `v↑↑` (panic at light speed) |
| **K (Rule/Contract)** | Stability, institutional trust, predictability | `ω→` (stable), `μ↑↑` (slow change), `v→` (official channels) |
| **P (Profit/Decay)** | Individual gain, speculation, inequality | `ω↑` (volatility), `λ↑↑` (short-term boom), `μ↓` (weakening institutions) |

This vector dynamically modulates the parameters of all other historical waves. The same economic shock can produce "mobilization" in `E` mode or "flight" in `P` mode.

## 🧬 Step 4: Cultural Code Vector — "Why Does the Same Shock Produce Different Outcomes?"

Same genetic pool, same infrastructure, same people. Only the chain **environmental stress → collective emotional regime → behavioral priority** changes. We code cultural code as a 6-dimensional dynamic latent vector:

```math
C(t) = [A, T, R, M, S, E]
```

| Component | Definition | Effect on Waves |
|-----------|------------|-----------------|
| `A` (Adaptation) | Flexibility to change/migration ("helium" vs. "molasses") | `λ` shifts positive; phase jumps stabilize quickly during crises |
| `T` (Trust in Authority) | Central state vs. tribe/network/informal networks | `T↓` → `μ↑` (institutional friction), `v↑` in informal networks |
| `R` (Curiosity/Risk) | Tolerance for exploration/innovation/experimentation | `R↓` → delayed adoption of new technology; older wave lengths extend |
| `M` (Memory/Experience) | "The sum of past betrayals" | Delayed feedback (`τ`); permanently shifts `φ` phase after shocks |
| `S` (Homogeneity) | Single block vs. regional/ideological factions? | `S↓` → multi-node network; increased local resonance/fracture points |
| `E` (Framework Flexibility) | Pragmatism vs. dogmatism | `E↑` → institutional reform flexibility ↑; `E↓` → polarization/lock-in ↑ |

> **Example:** In Turkey, regardless of official inflation, behavioral response is shaped by `T↓` (distrust of central authority) as `A↑` (migration/adaptation) + physical gold holding. The 5,000+ tons of gold is the tangible projection of cultural distrust.

## 🔁 Validation Protocol: "Not the Formula, but the Process Is Reliable"

1. **Credibility Weight (`CW`)**: Each data point is weighted by source diversity, victor bias, archaeological corroboration.
2. **Iterative Backtesting**: The model is trained on 70% of historical data, tested on 30%. If error is large, parameters are updated.
3. **Manipulation-Resistant Proxies**: Black market exchange rate instead of official inflation; birth rate, migration applications instead of "happiness" surveys.
4. **Uncertainty Band**: The model never makes point predictions; it presents `[Ψ_min, Ψ_most_likely, Ψ_max] ± Confidence_Interval`.
